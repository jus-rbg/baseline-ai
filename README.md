Baseline AI is an **AI-powered hackathon toolkit** designed to accelerate project setup, integrate Baseline web feature data, and enable **real-time collaboration** for developers. Built for the [Baseline Tooling Hackathon](https://baseline.devpost.com), this project helps teams create modern web solutions faster.

---

## 🧠 About the Project

### 🎯 Inspiration
Hackathons are fast-paced, and teams waste precious time setting up tools. **Baseline AI** solves this by giving you instant project scaffolds, AI-powered suggestions, and live team sync.

### 💡 What It Does
- 📦 One-click project initialization with Baseline web feature integration  
- 🤖 AI-driven suggestions for frameworks, tools, and code snippets  
- 🧑‍💻 Real-time team collaboration via dashboard  
- 📊 Visual reports on modern web feature adoption

### 🛠️ How We Built It
Built using:
- **Python + Flask** (backend)
- **JavaScript + HTML/CSS** (frontend)
- **Baseline Web Features API**
- **OpenAI API** for AI suggestions
- **SQLite** for local data
- **GitHub Actions** for CI/CD

### ⚔️ Challenges
- Integrating Baseline data seamlessly
- Designing intuitive AI prompts
- Syncing real-time data between collaborators

### 🏆 Accomplishments
- Fully functional AI-assisted toolkit
- Clean, modular architecture
- Real-time dashboard demo

### 📚 What We Learned
- Baseline’s role in web evolution  
- Building collaborative AI-powered tools  
- Optimizing hackathon workflows

### 🚀 What’s Next
- Expand to VS Code extension  
- Add multi-language AI code scaffolding  
- Deeper Baseline analytics
